# my-static-website
This project demonstrates how to host and deploy a static website (HTML, CSS, JavaScript) using cloud services integrated with GitHub for version control and continuous deployment. The website is stored in a GitHub repository, and any code changes pushed to the main branch automatically trigger a cloud deployment pipeline. The site is hosted on [Azure], with CDN (Azure CDN) for faster global delivery and IAM-based security for controlled access.

The setup ensures high availability, fault tolerance, and scalability, while integrating CI/CD automation to eliminate manual uploads. Security measures include HTTPS enforcement, firewall rules, and role-based access control (RBAC) for administrators.

Key Features:

GitHub repository for source control and automated deployment

Static website hosted on Azure Blob Storage with CDN support

Continuous Integration & Deployment (CI/CD) pipeline setup

IAM roles and RBAC for secure access management

Version tracking and rollback using Git

Fully automated, serverless, and cost-efficient deployment

Tools & Technologies: GitHub • GitHub Actions • Azure Blob Storage • Azure CDN • IAM / RBAC • HTML • CSS • JavaScript


Project Name: 🌐 “LiveStreamHub” — Automated Cloud Deployment of Static Websites

Description:
Developed and deployed “LiveStreamHub”, a fully automated, static website hosting solution using Azure Storage and GitHub Actions, featuring CI/CD, monitoring, and optional scalability upgrades. The project demonstrates proficiency in cloud infrastructure, DevOps practices, and automated deployments.

Key Highlights:

Automated CI/CD Pipeline: Integrated GitHub Actions to automatically deploy updates from the local repository to Azure $web container on every commit, ensuring zero manual effort.

Cloud-Based Hosting: Configured Azure Storage Account for static website hosting with immediate availability and scalability.

Monitoring & Logging: Enabled Azure Monitor metrics and diagnostic logs for traffic, latency, and request tracking. Created real-time alerts for downtime and high latency to ensure reliable uptime.

Security & Performance: Supports HTTPS (optional custom domain) and prepares the groundwork for CDN integration for faster global content delivery.

Scalability Ready: Architecture allows future upgrade to a dynamic web application with backend frameworks like Flask/Node.js/Django and database integration (Azure SQL / Cosmos DB).

Tech Stack & Tools:
Azure Storage Account | GitHub Actions (CI/CD) | HTML, CSS, JavaScript | Azure Monitor & Diagnostic Logs |
